# Vendored game data

| File | What | Source |
|---|---|---|
| `entity_identifiers.dat` | Vanilla entity list (network NBT), sent as the AvailableActorIdentifiers packet body | [GeyserMC/Geyser](https://github.com/GeyserMC/Geyser) `core/src/main/resources/bedrock/entity_identifiers.dat`, MIT licence, Copyright (c) GeyserMC. Full notice: [LICENSE-GeyserMC](LICENSE-GeyserMC) |
| `java_blocks.bin` | For each Java 26.3 block state id, the Bedrock network block hash (u32 LE) | Generated by `tools/gen_block_table.py` from [GeyserMC/mappings](https://github.com/GeyserMC/mappings) `blocks.nbt` at commit `b4cec82` (the version Geyser pins for Java 26.3; MIT, Copyright (c) GeyserMC, same notice as above) plus Minecraft's `blocks.json` data report for the Java names. Regenerate when Horizon moves to a new Java version. |
| `item_registry.bin`, `creative_content.bin` | ItemRegistry and CreativeContent packet bodies for Bedrock 26.60 (all items with their components; the creative menu) | Generated by `tools/gen_item_data.py` from GeyserMC/Geyser `core/src/main/resources/bedrock/` `runtime_item_states.26_60.json`, `item_components.26_60.nbt` and `creative_items.26_60.json` (MIT, same notice). Checked byte for byte against Mojang's server. Regenerate for a new Bedrock version. |
| `crafting_data.bin`, `recipe_java.bin` | CraftingData packet body (Bedrock's crafting-table recipes, shaped then shapeless) and, per recipe network id, its output's Java item and count | Generated by `tools/gen_recipes.py` from [pmmp/BedrockData](https://github.com/pmmp/BedrockData) `recipes/shaped_crafting.json` and `recipes/shapeless_crafting.json` at tag `bedrock-1.26.30` (CC0-1.0, public domain), with Geyser's item data above for item ids. Bedrock only displays results from these; Horizon does the crafting. |
| `java_biomes.json` | Java biome name to Bedrock biome id | Copied from [GeyserMC/mappings](https://github.com/GeyserMC/mappings) `biomes.json` at commit `b4cec82` (MIT, same notice). |
| `java_chests.txt` | Java 26.3 chest and trapped chest states: the other half's offset and whether the half leads on Bedrock | Generated by `tools/gen_block_table.py` from Minecraft's `blocks.json` data report (pairing rule as Geyser's DoubleChestBlockEntityTranslator). |
| `block_properties.bin` | StartGame's block properties: the 98 vanilla blocks Bedrock 26.60 defines data-driven (concrete stairs, slabs, walls...) | Generated by `tools/gen_item_data.py` from GeyserMC/Geyser `core/src/main/resources/bedrock/data_driven_blocks.26_60.nbt` (MIT, same notice). Found byte for byte in Mojang's server's StartGame. |
| `creative_java.bin` | For each creative menu entry, the Java 26.3 item it gives | Generated by `tools/gen_item_data.py` from the creative items and GeyserMC/mappings `items.json` (MIT, same notice). |
| `java_items.bin` | For each Java 26.3 item id: Bedrock item id, aux value and the Java block state it places | Generated by `tools/gen_item_data.py` from GeyserMC/mappings `items.json` at commit `b4cec82` (MIT, same notice) plus Minecraft's `registries.json` data report for the Java item ids. |
| `java_dig.bin`, `java_tools.txt` | For each Java 26.3 block state: hardness, needs-a-tool, and which tool block sets hold it; each tool item's mining rules. Times Bedrock's crack animation as Java mines. | Generated by `tools/gen_dig_data.py` from the game data Horizon's launcher extracts (`gameplay-facts.json`, `facts.json`, `block-tags.json`, `items.json`) and the `registries.json` data report. |
| `java_waterlogged.bin` | A bit per Java 26.3 block state: it holds water (waterlogged, or seagrass, kelp and bubble columns), which Bedrock draws as a second block layer | Generated by `tools/gen_block_table.py` from Minecraft's `blocks.json` data report. |
| `biome_definitions.bin` | BiomeDefinitionList packet body for Bedrock 26.60: every vanilla biome (climate, water colour, tags). Without it the client draws a grey sky and colourless water | Generated by `tools/gen_biome_data.py` from GeyserMC/Geyser `core/src/main/resources/bedrock/stripped_biome_definitions.json` (MIT, same notice). |
